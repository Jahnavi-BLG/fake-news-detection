01

News Article Text Input

User Submission Phase

The user enters an article headline and text body through the web application interface. The combined text string is validated before being passed down the Natural Language Processing pipeline.

02

Text Preprocessing & Cleaning

Natural Language Processing

The raw news text undergoes text normalization: converting text to lowercase, removing irrelevant punctuation, stripping numbers, and filtering out common English stop-words (such as "the", "is", "at").

03

TF-IDF Vectorization

Feature Extraction Matrix

The preprocessed text is transformed into a high-dimensional numerical feature vector using Term Frequency-Inverse Document Frequency (TF-IDF) based on a vocabulary of 50,000 learned features. Words frequent in an article but rare across general news receive higher weight scores.

04

Logistic Regression Classifier

Machine Learning Model

The vectorized feature array is evaluated by the trained Logistic Regression model. The algorithm computes a weighted linear combination of word features and passes it through a sigmoid function to evaluate probability scores.

05

AI Prediction & Classification Output

Real / Fake Decision Output

If the model's computed probability score corresponds to class 1, the article is classified as REAL NEWS. If class 0, it is classified as FAKE NEWS. The result is immediately returned and displayed on the Web Dashboard.
